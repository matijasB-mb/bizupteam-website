# Hero media

The hero is already wired for the cinematic film. Drop two files here and it
picks them up — no code change anywhere.

| File              | What it is                        | Notes                                    |
| ----------------- | --------------------------------- | ---------------------------------------- |
| `hero.mp4`        | The Highfield film, looping       | H.264, ~1920×1080, muted, target < 6 MB  |
| `hero-poster.jpg` | First frame of the film           | Same aspect ratio, ~1920×1080, < 250 KB  |

Until both exist the hero renders its composed CSS scene instead: a dark
architectural field with a red spill low-left. That is a designed fallback, not
a placeholder — the page is presentable today.

## Shooting notes for the film

Slow camera move through a modern office. The frame passes a phone on a desk
(A1), then a Canon multifunction device, then settles on the wider room. Cool
daylight, deep shadows, no people. It sits behind a dark scrim at 70 % opacity,
so favour contrast and simple shapes over fine detail — anything small will be
lost under the text.

Keep the loop point invisible: start and end on the same framing.
